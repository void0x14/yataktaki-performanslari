# Teknik Şartnameler Dizini (`specs/`)

Bu dizin, `.codex/skills/project-orchestration/SKILL.md` politikasına uygun olarak **kapsamlı uygulamalar başlamadan önceki teknik şartnameler** için kullanılır.

Uygulama başlamadan önce şartnameyi oluşturun veya güncelleyin. Şartname, uygulayıcının büyük mimari kararlar icat etmesini önlemeli ve tekdüze (öngörülebilir) kodlamayı sağlamalıdır.

## Standart Şartname Formatı

```markdown
# <Görev / özellik>

## Hedef
## Hariç tutulan hedefler (Non-goals)
## Mevcut durum
## İstenen durum
## Gereksinimler
## Kısıtlamalar / değişmezler (invariants)
## Etkilenen alanlar
## Uyumluluk gereksinimleri
## Riskler / uç durumlar
## Kabul kriterleri
## Doğrulama
## Uygulama notları
```
