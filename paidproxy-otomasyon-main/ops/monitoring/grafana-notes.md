# Dashboards

Export Prometheus metrics from `/metrics`.

AI/decision: throughput, queue age, schema success, provider errors, cost, top-k, nDCG, regret, calibration, disagreement, override rate.

Scan/validation: L4 probes/s, L7 attempts/s, yield per ASN/prefix, high-value assets, timeout/retry/breaker, echo health.

System: DB writer lag, WAL size, segment queue depth, spool usage, disk/CPU/RAM/FD, backup age.
