# L7 protocols

Initial protocols: HTTP CONNECT, SOCKS5, SOCKS4/SOCKS4a.

Execution order is not a global hardcode. It comes from the operator execution profile or the Stage-1 per-target protocol intent.

`VALIDATED` requires a valid handshake, proxied reachability to a controlled echo target, matching nonce/request id, verified exit IP, no direct-connect confusion, and recorded latency/error metadata.
