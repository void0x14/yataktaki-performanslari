## Validation rules

1. Explicit probe/serve mode; no implicit adoption from an arbitrary socket.
2. Exact root and old-agentd identity.
3. Candidate set includes persisted running, paused, and stopping records with PID/PGID.
4. PID, PGID, starttime and current PaidProxy worker cmdline/agent id must match.
5. Probe requires worker PPID to be current old agentd.
6. stdout/stderr must be pipes and each must map to exactly one old-agentd read FD.
7. Duplicate inode must match by fstat; duplicate is never read and is closed.
8. Duplicate worker pipe inodes, malformed IDs, missing streams, incomplete sets, PID/PGID/starttime mismatches and live terminal workers fail closed.
9. Receiver validates the complete live candidate set and every passed FD before adoption.
10. Adopted workers preserve PID/PGID controls and existing stream ingestion; exit code is never fabricated.
