# Araştırma Raporları Dizini (`reports/`)

Bu dizin, `.codex/skills/project-orchestration/SKILL.md` politikasına uygun olarak **yeniden kullanılabilir araştırma bilgisi** için kullanılır.

Aşağıdakilerden en az biri doğru olduğunda bir rapor oluşturun:
- Araştırma geniş kapsamlı veya maliyetliydi.
- Sonucun oturumlar arası yeniden kullanılması muhtemeldir.
- Bulgular bir mimari/şartname kararını gerekçelendirmektedir.

## Standart Rapor Formatı

```markdown
# <Araştırma başlığı>

Oluşturulma: <YYYY-MM-DD HH:MM>
Dayandığı Git HEAD: <commit hash>
İncelenen alan: <ne incelendi>

## Soru
## Doğrulanmış gerçekler
## Varsayımlar
## Bilinmeyenler
## Riskler
## Öneriler
## Kanıtlar / incelenen dosyalar
```
